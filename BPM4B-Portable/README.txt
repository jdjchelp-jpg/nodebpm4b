BPM4B Professional Audiobook Converter - Portable Edition v12.0.0
=================================================================

QUICK START
-----------
1. Double-click on "BPM4B-Launcher.bat"
2. Wait for the browser to open automatically
3. Start converting your documents to audiobooks!

WHAT'S INCLUDED
---------------
- Local Kokoro-82M TTS Engine (AI voice synthesis)
- PDF/DOCX/TXT/EPUB document support
- Automatic chapter detection
- Premium audio conversion (M4B/MP3)
- No installation required
- No internet connection required for TTS

SYSTEM REQUIREMENTS
-------------------
- Windows 10 or later (64-bit)
- 4GB RAM minimum (8GB recommended)
- 500MB free disk space

HOW TO USE
----------
1. DOCUMENT TO AUDIOBOOK:
   - Click "Browse" and select your document
   - Choose voice and quality settings
   - Click "Generate Audiobook"
   - Download your M4B file

2. MP3 TO M4B CONVERSION:
   - Upload MP3 files
   - Add chapter markers (optional)
   - Set metadata and cover art
   - Convert to M4B format

TROUBLESHOOTING
---------------
- If the browser doesn't open: Visit http://localhost:3000 manually
- If server won't start: Make sure port 3000 is not in use by another app
- For large documents: The process may take several minutes
